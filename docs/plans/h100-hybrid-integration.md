# H100 混合推理接入计划

## 当前边界

Pi 5 的第一阶段是纯网页/API 中转。H100 不参与任务，也不会因为用户打开 ComfyUI 页面而占用算力或显存。

以后要在同一个工作流里混合以下两类节点：

- Kling、Runway 等第三方闭源 API 节点；
- Flux、LTX 等由 H100 执行的本地开源模型节点。

这不能仅靠给 Pi 5 配置一个远程 GPU 地址自动实现。ComfyUI 节点默认在当前后端进程执行，必须建立明确的远程执行边界。

## 推荐方案：H100 独立模型服务

在 H100 上运行独立的模型服务，Pi 5 通过专用自定义节点调用它：

```text
ComfyUI 工作流（Pi 5）
  |
  +--> 第三方 API 节点 ----------> 外部供应商
  |
  +--> H100 远程推理节点 --------> H100 模型服务
                                      |
                                      +--> Flux / LTX / 其他本地模型
```

Pi 5 上的节点负责参数校验、任务提交、状态轮询、取消和结果转换；H100 服务负责模型加载、显存管理、推理和结果产出。

优点：

- Pi 5 与 H100 的职责清晰；
- H100 不需要公开 ComfyUI 管理界面；
- 可以单独限制并发、队列和模型生命周期；
- 第三方 API 与 H100 节点可以出现在同一工作流中；
- H100 服务可以在空闲时卸载模型或保持热加载，由服务端策略决定。

## 备选方案：H100 运行第二套 ComfyUI

H100 可以运行第二套 ComfyUI，Pi 5 通过远程执行节点向它提交完整子工作流。这适合复用已有 H100 工作流，但需要额外解决：

- 子工作流的版本和节点一致性；
- 输入文件上传和输出文件下载；
- 两套 ComfyUI 的队列、取消和错误映射；
- 工作流拆分边界；
- H100 端自定义节点和模型版本管理。

如果只需要几个稳定的远程模型节点，优先采用独立模型服务；如果需要直接复用复杂的 H100 ComfyUI 工作流，再评估第二套 ComfyUI。

## 远程任务协议

无论选择哪种后端，接口至少需要支持：

1. 提交任务并返回稳定的任务 ID；
2. 查询排队、运行、成功、失败和取消状态；
3. 取消尚未完成的任务；
4. 返回结构化错误，不只返回服务端日志；
5. 上传输入或引用受控的对象存储地址；
6. 下载结果并校验大小、类型和完整性；
7. 设置连接超时、任务超时和最大重试次数；
8. 使用幂等键避免网络重试造成重复推理。

节点输出应转换为 ComfyUI 已有的数据类型。不要为了远程执行修改共享核心接口或让核心执行层理解 H100、供应商账号、任务 ID等外部概念。

## 网络与鉴权

- H100 仅通过 Tailscale、内网 VPN 或隔离网络供 Pi 5 访问。
- 不把 H100 推理端口直接发布到公网。
- Pi 5 到 H100 使用独立服务凭据，并支持撤销和轮换。
- 凭据不写入工作流 JSON。
- H100 服务只允许必要的模型、参数范围和文件类型。
- 对上传大小、输出大小、并发数和任务时长设置硬限制。

## 模型与显存策略

模型加载策略由 H100 服务拥有，而不是由 Pi 5 或通用 ComfyUI 核心控制。需要为每个模型明确：

- 常驻、按需加载或空闲卸载；
- 最大并发数；
- 显存预算；
- 请求排队上限；
- 模型版本和权重校验；
- 服务重启后的任务处理方式。

“ComfyUI 空闲时是否占用 H100 显存”取决于 H100 服务的模型卸载策略，不应通过 Pi 5 猜测远端状态。

## 分阶段实施

### H1：协议原型

- 只接一个低风险模型；
- 固定输入和输出类型；
- 验证提交、轮询、取消和失败处理；
- 不与第三方 API 节点串联。

### H2：ComfyUI 节点

- 实现一个模型专用远程节点；
- 不修改 ComfyUI 核心接口；
- 将远端返回规范化为标准 ComfyUI 类型；
- 验证中断、超时和重复提交。

### H3：混合工作流

- 将一个第三方 API 节点和一个 H100 节点放入同一工作流；
- 验证大文件传输和中间结果持久化；
- 验证任一后端失败时工作流错误可定位。

### H4：生产化

- 加入队列限制、审计、指标和容量告警；
- 完成服务凭据轮换；
- 演练 H100 不可用、Pi 5 重启和网络中断；
- 固定模型、服务和节点版本。

## 执行前待定

- H100 上采用独立模型服务还是第二套 ComfyUI；
- 首个本地模型及输入输出契约；
- Pi 5 与 H100 之间的私网方式；
- 文件通过请求体、共享存储还是对象存储传输；
- 模型空闲卸载时间和最大并发数；
- 谁负责维护远程节点和服务端协议版本。
